## 📋 Опис проєкту

**TechVolt** — це сучасний багатосторінковий інтернет-магазин електроніки, розроблений як бакалаврський проєкт. Сайт демонструє повний цикл клієнтської частини e-commerce застосунку.

### Функціональність

- 🏠 **Головна сторінка** — hero-секція, категорії, хіти продажів, промо-банер, переваги
- 🛍️ **Каталог** — фільтрація за категорією, ціною, рейтингом; сортування
- 🛒 **Кошик** — додавання/видалення товарів, зміна кількості, підрахунок суми
- ℹ️ **Про нас** — інформація про компанію, команда, статистика
- 📞 **Контакти** — форма зворотного зв'язку, контактна інформація
- 📱 **Адаптивна вeрстка** — повна підтримка мобільних пристроїв

## 🗂️ Структура проєкту

```
techvolt/
├── index.html              # Головна сторінка
├── pages/
│   ├── catalog.html        # Каталог товарів з фільтрами
│   ├── cart.html           # Сторінка кошика
│   ├── about.html          # Сторінка "Про нас"
│   └── contact.html        # Контактна сторінка
├── css/
│   └── style.css           # Головні стилі (CSS-змінні, компоненти, адаптив)
├── js/
│   ├── data.js             # База даних товарів + утиліти кошика
│   └── main.js             # Основна логіка (навігація, рендер карток)
├── .gitignore              # Виключення для Git
├── README.md               # Цей файл
└── LICENSE                 # MIT ліцензія
```

## 🚀 Як запустити

### Локально

```bash
# Клонувати репозиторій
git clone https://github.com/YOUR_USERNAME/techvolt.git

# Перейти до директорії
cd techvolt

# Відкрити в браузері
open index.html
# або просто двічі клікнути на index.html
```

### GitHub Pages

1. Зайдіть у **Settings → Pages**
2. Source: **Deploy from a branch → main → / (root)**
3. Сайт буде доступний за адресою: `https://YOUR_USERNAME.github.io/techvolt/`

## 🎨 Дизайн

- **Колірна схема:** темна тема (#0a0a0f) з жовтим акцентом (#e8ff00)
- **Шрифти:** Syne (заголовки) + DM Sans (текст)
- **Стиль:** Dark mode / Futuristic minimal
- **Анімації:** CSS keyframes, плаваючі елементи, fade-in
